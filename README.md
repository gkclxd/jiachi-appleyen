# 小顏選刷手平台（示範）

刷手平台的可操作示範頁，單一 HTML 檔，不需要安裝或建置。

> 頁面中的姓名、編號、金額、訂單與帳號**全部為虛構資料**，不連接任何真實資料庫、Google 試算表或 API。

## 內容

| 畫面 | 說明 |
| --- | --- |
| 我的進度 | 進貨／蝦皮四階段（待補資料、待核對、已排入撥款、已匯款），可切換編號 |
| 款項 | 撥款批次，依編號列出匯入帳戶與金額 |
| 進度明細 | 依類別、編號、狀態篩選；蝦皮顯示「金額 × 補貼率」 |
| 進貨請款 | 每箱逐筆填寫撥款編號、請款代碼（手寫或選擇）、發票；以箱號為唯一碼覆蓋修改 |
| 新增蝦皮訂單 | 訂單編號、發票、折扣前金額；檢查格式、切換日與重複登記 |
| 我的資料／綁定編號 | 每個編號對應一個收款帳戶；綁定需事務所核准 |
| 問答 | 示範版以規則回答，正式版改接 GPT（OpenAI API），只能查詢與解釋 |

右上角「示範操作」可模擬後台動作：倉管理貨、事務所彙整、Eddie 匯款、補分行代號、核准綁定、標註退貨。重新整理頁面即回到初始資料。

## 用 GitHub Pages 發布

1. 在 GitHub 建立新的 repository（例如 `brush-portal-demo`）。
2. 上傳本資料夾內的檔案（`index.html`、`.nojekyll`、`README.md`）到 repository 根目錄。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 約 1–2 分鐘後，網址為 `https://<你的帳號>.github.io/brush-portal-demo/`。

注意：GitHub Pages 的網址是**公開的**，任何拿到網址的人都能瀏覽。請勿放入真實刷手資料。若 repository 設為 private，需 GitHub 付費方案才能使用 Pages。

## 本機瀏覽

直接用瀏覽器開啟 `index.html` 即可。手機寬度顯示手機版，960px 以上顯示桌機版（左側選單）。
